# Screenshots

Bilder für die README. Auf deinem Rechner (GPU-Browser) einfach die Galaxy
öffnen und Screenshot machen, dann hier ablegen:

- `universe.png` — Universum-Layout, Übersicht (mehrere Galaxien sichtbar)
- `themes.png` — 🧠 Themen-Sicht
- `mobile.png` — mobile Ansicht (Phone)

Wichtig: nur Aufnahmen mit Demo-Daten (`?benchgraph=` auf toten Port →
Demo-Vault) oder synthetischem Vault (`make_synth_vault.py`) — nie mit
persönlichen Vault-Inhalten, dieses Repo ist öffentlich!
