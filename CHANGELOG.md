# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-24

### Added

- Initial public release.
- Universe visualization: note clusters as spiral galaxies with bright
  cores, spiral arms and voids between galaxies.
- Deterministic layouts (universe / sphere / force) with a zero-overlap
  guarantee and deterministic community detection.
- Gesture control: offline hand tracking (MediaPipe, locally vendored)
  via webcam or phone camera.
- Phone capture: jot notes on the phone, they land in the inbox and
  appear as new stars.
- Demo mode: procedural demo vault, runs without a backend.
